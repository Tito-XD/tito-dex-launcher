# Launcher 视觉与触屏约定

Launcher 延续 TitoDex 的训练家手帐、固态塑料和扁平贴纸，但以掌机桌面的壁纸露出、模块整理和触屏/按键双输入为中心。当前实现由 `app/src/main/kotlin/com/tito/titodex/launcher/ui/Theme.kt` 定义，不依赖 Flutter token。

| 主题 | 表面 | 交互性格 |
| --- | --- | --- |
| 训练家手帐 | 暖纸、灰蓝细边、短纸边阴影，克制的胶带装饰 | 轻落、压下、短落定 |
| 固态塑料 | 暖白哑光、固定圆角、弱内边与轻投影 | 有阻尼的回弹，普通应用图标不套框 |
| 扁平贴纸 | 大色块、干净实色、珊瑚重点色 | 短、清晰、快速收束 |

主要颜色：深蓝 `#2F4361`、奶油 `#FFF7E6`、纸色 `#FFFAF0`、珊瑚 `#FF8F6A`、浅黄 `#F7D977`。字体为内置 Nunito，中文由系统回退。颜色与材质保留主题差异，密集信息表面优先保证可读性。

## 尺寸与对齐

- `LauncherCorners` 统一固定：卡片/弹层 16dp、控件 12dp、小贴纸/默认头像 8dp，禁止误用整数百分比圆角。
- 横排时钟时间独占第一行；日期、镂空 `MON` / `SUN` / `SAT` 与天气同在第二行，两行各自居中。1×2 竖排规格保留。
- 时间按可用面积放大。日期、星期、天气图标和温度按实际可见像素居中；下排与时间保留 10dp 布局间隔。
- 名片头像按称呼/问候两行可见字形总高度对齐，默认圆角矩形，可切换圆形。
- 天气顶部楼房图标与城市名打开城市选择，左下刷新，右下叉号只收起卡片。图标操作保留 44dp 点击高度和中文读屏。
- 系统栏透明，内容避让真实系统留边；导航提示保留原版胶囊，不覆盖模块。

## 动效与输入

初次加载后逐项淡入轻落；壁纸变化交叉过渡，布局位置和尺寸同步移动，名片从添加处归位，手柄焦点框滑动。快速反向操作可以中断，实际焦点立即生效，拖动直接跟手。关闭动态效果或系统禁用动画时立即到位。禁止无必要常驻循环、图标外发光和复杂实时模糊。

细节见 [ADAPTIVE_LAYOUT](../ADAPTIVE_LAYOUT.md) 与 [MOTION](../MOTION.md)。旧浏览器原型仅作为设计历史，不能覆盖原生组件的最新约定。
